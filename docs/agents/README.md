# Agent guides

Short working rules for anyone's coding agent, and for the people driving one. `AGENTS.md` holds the rules for every
change; these go deeper on one topic each. A rule marked **gate** is enforced by a check. A rule marked **review** is
held only by reviewers, so an agent has to know it.

| Guide | Read it when |
| --- | --- |
| [Native evidence](native-evidence.md) | A change or verdict rests on what the original game does |
| [Reviews and merges](reviews-and-merges.md) | You open, review or land a PR |
| [Persistence](persistence.md) | You change what the server saves |
| [Client gates](client-gates.md) | You add a client module or change client behaviour |
| [Windows tooling](windows-tooling.md) | You run gates or scripts on Windows |
