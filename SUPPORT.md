# Support

## Getting help

- **Working on the code:** start with [CONTRIBUTING.md](CONTRIBUTING.md), then ask in #🛠️contributing on [Discord](https://discord.gg/RUua9HY657) or open an [issue](https://github.com/opensro-dev/opensro/issues).
- **A security problem:** follow [SECURITY.md](SECURITY.md). Please don't post it publicly.

## Supporting development

OpenSRO is open-source software. If the code is useful to you, you can support its development on **[Ko-fi](https://ko-fi.com/opensro)**. It is never required.

No one makes money from OpenSRO. It's built by volunteers who put in their own time and money because they love the game, and every donation goes back into development.

1. **Open source forever:** OpenSRO is and will always stay open source, so anyone can learn from it and build on it.
2. **Development only:** donations fund development of this repository: dev tools, CI and documentation.
3. **A thank-you, nothing more:** a donation buys no access, items, perks or advantages of any kind.
4. **Never required:** the code is the same for everyone, under the [AGPL](LICENSE).
